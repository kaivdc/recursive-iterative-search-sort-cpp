# Recursive and iterative Search and Sort Implementation
A simple comparative implementation of search and sort operations when done recursively and iteratively. Repository has 2 files, one for the sort implementations, and one for the search. Names should be self explanatory. Showcases:
 - Understanding of efficient coding strategies
 - Understanding of search and sort algorithms
All code done in Visual Studio Code, should be runnable by any software that can execute a cpp file.
